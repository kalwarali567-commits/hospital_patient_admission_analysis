**Hospital Patient Admission Analysis** 
****Overview**
Analyzed hospital admission data to identify trends in patient admissions, length of stay (LOS), disease burden, and resource utilization. The project focused on healthcare operational analytics using SQL, data cleaning workflows, and structured analysis.

**Business Questions**
Which admission types contribute most to hospital utilization?
Which diagnoses are associated with longer hospital stays?
What patient demographics contribute most to admissions?
Are there repeat admission patterns among patients?

**Dataset**

**Healthcare admissions dataset containing:**

patient demographics
admission/discharge dates
diagnoses
medications
admission types

Each row represents one hospital admission.

**Tools Used**
SQL (PostgreSQL)
Python (Pandas)
Tableau
GitHub

**Data Preparation**
Cleaned inconsistent categorical values
Corrected schema mismatches
Validated admission/discharge logic
Used staging tables for safe data loading
Normalized data into patient, admission, and diagnosis tables

**Analysis Performed**
Admission trends by type
Average LOS analysis
Disease burden analysis
Repeat patient analysis
Demographic-based admission trends
High LOS outlier identification

**Key Findings**
Emergency admissions contributed the highest patient volume
Certain diagnoses showed longer average LOS
Repeat admissions indicated potential chronic care patterns
Older patient groups showed higher healthcare utilization

**Dashboard**

**Created a Tableau dashboard to visualize:**

admission trends
LOS metrics
diagnosis distribution
demographic filters

**Key Learnings**
Importance of data grain in healthcare analytics
Real-world datasets require significant validation and cleaning
SQL is effective for operational healthcare analysis
Structured staging workflows improve data reliability
